# TTS、SST 与语音克隆的理论与应用

**课程名称：** TTS、SST 与语音克隆的理论与应用（人才培养方案课程 26，课程代码 5371）

**授课对象：** 成人教育（开放教育）人工智能技术应用专业专科学生，多为在职学习者，线上自学为主

**学分学时：** 4 学分，72 学时（理论 36 学时，其中线上 22、线下 14；实验 36 学时，线上），第 4 学期开设，期末开卷考试

**先修要求：** 先修本专业的《Python 编程》（本系列另编教材），本书不再讲 Python 语法，代码里遇到语法只给一句提示并链接到《Python 编程》。学过“人工智能导论”更好，用到的机器学习、神经网络概念在使用处用一段速记和生活比喻讲清。

**对应证书：** 人才培养方案没有给本课挂证书。

**名称说明：** 方案里的 SST 指“语音识别与合成”。业内更常见的写法是 STT（Speech to Text，语音转文字）或 ASR（自动语音识别）。本书正文用“语音识别（ASR）”和“语音合成（TTS）”，课程名保留方案原文。

## 课程概述

手机里说一句“明天早上七点叫我起床”就能设好闹钟，导航软件用明星的声音播报路况，会议软件一边开会一边出字幕，短视频里的配音不再需要真人录。背后是三项语音技术：把声音变成文字的语音识别，把文字变成声音的语音合成，以及只听几秒钟就能“学会”一个人声音的语音克隆。

本课程面向几乎没有编程经验的学生，目标是“**能理解是底线，能用是加分**”：学完能说清一段语音从录音、特征、模型到结果的每一步在做什么，能读懂、运行并修改给定的代码，能用现成模型做出语音转写、有声书、语音小助手这样能演示的小应用，并且知道克隆别人的声音之前必须做什么。课程采用“先听到效果、再讲原理”的顺序：第 1 章就用几行代码让电脑说话、听写；之后讲声音怎样变成数字，语音识别从模板匹配、隐马尔可夫模型到深度学习的原理与实战，语音合成的文本前端、声学模型和声码器，声纹识别与语音转换，语音克隆的技术、伦理与授权，最后把识别和合成连成一个语音交互应用。

全书 9 章、36 个实验。实验以开源工具 sherpa-onnx（新一代 Kaldi 团队开发，识别、合成、唤醒、声纹、克隆是同一套写法）为主，模型是几十到几百兆的离线小模型，大多数实验在普通电脑 CPU 上几十秒内就能跑完，不需要联网调用付费接口；需要显卡的微调式克隆在云端 Notebook 上完成，学校的 A40 服务器用于课堂演示和编者实测。每个实验分“跑通”“改一改”“挑战”三档，前两档必做，给出完整代码，学生只需按提示修改。

## 主要内容

- 语音技术的版图：语音识别、语音合成、语音克隆、声纹识别、语音唤醒；实验环境
- 零基础够用的 Python（约 15 个知识点，边用边学）
- 声音的数字化：声波、采样率、位深、声道；波形图、频谱、语谱图、梅尔频谱与 MFCC；剪辑、音量归一化、去静音、降噪
- 语音识别原理：特征提取、声学模型、语言模型、解码与词图搜索；模板匹配（DTW）、隐马尔可夫模型（HMM）、深度神经网络与端到端模型（CTC、Whisper、Paraformer、SenseVoice）；字错率
- 语音识别实战：多模型对比、长录音转写与字幕、语音活动检测、标点恢复、流式识别、关键词唤醒、噪声与口音
- 语音合成原理：文本前端（文本正则化、分词、多音字、拼音、韵律）、声学模型、声码器；拼接合成、HMM 参数合成、深度学习合成（Tacotron、FastSpeech、VITS、Matcha）、大模型语音合成；主观与客观评价
- 语音合成实战：多说话人、语速与停顿、中英混读、有声书生成、云平台语音合成接口
- 声纹识别与语音转换：声纹嵌入、说话人确认、说话人日志、误接受与误拒绝；语音转换的思路
- 语音克隆：微调式与零样本两条路线、参考音频准备、克隆质量评价；授权与同意、法律法规、内容标识与水印、反诈
- 语音交互应用：语音助手链路（识别、理解、合成）、语音大模型、行业案例、网页小工具、性能与用户体验评估；隐私与社会影响

## 与其他课程的分工

- **人工智能导论**第 7 章只做语音产品体验，本课从原理到代码完整讲。
- **人工智能开发框架技术**第 10 章已经训练过语音指令识别器（声谱图当图片分类），本课不重复训练神经网络，需要时链接过去；本课用到的少量 PyTorch 代码只读不写，写法与开发框架课第 5 章“打开盒子”一致。
- **自然语言处理导论**讲过分词、语言模型和大模型，本课只在语音里用到时简讲并链接。
- **机器学习**讲聚类、相似度、阈值与评估指标，本课在声纹一章直接用结论。
- 本课是语音识别、语音合成、声纹识别和语音克隆的“主讲课”，也是全系列讲“声音权益与深度合成合规”的主讲课。

## 学习目标

按 2001 版布鲁姆分类法组织。

### 记忆

- 说出语音识别、语音合成、语音克隆、声纹识别、语音唤醒分别做什么
- 说出采样率、位深、声道、语谱图、梅尔频谱、MFCC 的含义
- 说出语音识别系统的四个组成部分和语音合成系统的三个组成部分
- 列举语音合成方法的四个发展阶段和各自的代表技术
- 说出与声音权益和深度合成有关的主要法律法规条款

### 理解

- 用生活比喻解释采样和量化，说明 16 kHz 为什么够语音识别用
- 解释语谱图上横轴、纵轴、颜色各代表什么，看图说出哪里有人说话
- 解释 HMM 和深度学习端到端模型的直观区别，以及语言模型为什么能纠正同音字
- 解释文本前端为什么要把“2026 年”“3.5%”“重庆”变成正确的读音
- 解释零样本克隆和微调式克隆的区别，以及声纹相似度怎样衡量“像不像”
- 解释为什么克隆别人的声音必须取得单独同意，合成音频为什么要加标识

### 应用

- 用 Python 读写、剪辑、重采样音频，画出波形和语谱图
- 用现成模型把录音转成带标点、带时间戳的文字和字幕
- 用现成模型把文字合成为指定音色、语速的语音，批量生成有声书
- 用声纹模型比对两段语音是否为同一人
- 在取得授权的前提下，用一段参考音频零样本克隆声音，并给输出加标识

### 分析

- 用字错率比较不同识别模型、不同噪声条件下的效果，找出出错原因
- 拆解一个语音产品用了哪些模块，指出延迟主要花在哪里
- 读懂常见报错，判断是路径、采样率、声道还是模型配置的问题

### 评价

- 用平均意见分（MOS）、字错率和声纹相似度评价合成与克隆效果
- 判断一个语音克隆的应用场景是否合规，指出缺少哪些授权或标识
- 在速度、准确率、资源占用之间为一个场景选择合适的模型

### 创造

- 设计并实现一个语音小应用（会议纪要助手、有声书工坊、智能客服、无障碍字幕四选一），完成项目报告和合规自查表
