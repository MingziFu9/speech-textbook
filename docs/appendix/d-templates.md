# 附录 D 实验报告、声音授权书与项目模板

本附录的四份模板都可以直接打印，或者复制到 Word 里填写。使用顺序一般是：**签授权书 → 做实验、写实验报告 → 做综合项目、写项目报告 → 填合规自查表**。

## D.1 实验报告模板 { #d1 }

每个实验交一份。“实验报告要求”里另有规定的（例如要交截图、记录表），按该实验的要求补充。

    **姓名**：＿＿＿＿　**学号**：＿＿＿＿　**班级**：＿＿＿＿　**日期**：＿＿＿＿

    **一、实验目的**（照抄或用自己的话写 2—3 条）

    **二、实验环境**

    | 项目 | 填写 |
    |---|---|
    | 电脑或云平台 | 例如：自己的笔记本（4 核 8 GB）/ 魔搭 Notebook |
    | Python 和 sherpa-onnx 版本 | 例如：3.12 / 2.0.1 |

    |---|---|---|

## D.2 声音使用授权书 { #d2 }

凡是使用真人的声音做克隆、做声纹，都要先签这份授权书（第 8.7 节）。课程作业用自己的声音时，授权人和被授权人都写自己，用途写“《TTS、SST 与语音克隆》课程实验作业”，发布范围写“仅提交给任课教师”。

    **被授权人**：＿＿＿＿（单位或个人），联系人＿＿＿＿，联系电话＿＿＿＿

    本人自愿授权被授权人在以下范围内采集和使用本人的声音：

    1. **采集内容**：本人朗读指定文字的录音共＿＿段，总时长约＿＿分钟。
    2. **使用方式**：使用语音合成和语音克隆技术，以本人的声音生成新的语音内容。
    3. **用途**：仅用于＿＿＿＿＿＿＿＿（例如：幸福里社区通知广播）。**不得**用于广告代言、商业营销、政治宣传、娱乐恶搞、冒充本人与他人沟通，以及其他本授权书未列明的用途。
    4. **发布范围**：＿＿＿＿＿＿＿＿（例如：社区广播站、社区业主微信群）。
    5. **期限**：自＿＿年＿＿月＿＿日至＿＿年＿＿月＿＿日。

    授权人签字：＿＿＿＿　　日期：＿＿＿＿
    被授权人签字（盖章）：＿＿＿＿　　日期：＿＿＿＿

!!! warning "使用这份模板要注意"
    - 这是教学用模板，帮助你把该约定的事项想全。正式的商业合作，请由单位法务或律师审核。
    - 授权人是未成年人的，要由监护人同意并签字。
    - **一份授权书只管一种用途**。用途、发布范围变了，要重新取得授权。
    - 授权书和录音分开保管；授权撤回或到期后，按约定删除并做好记录。
