## 课程与学习方法 { #faq-1 }

??? question "我几乎没学过编程，能学会这门课吗？"

    能。本书的代码都是“改参数、看结果”式的：每个实验先完整运行一遍，再按“改一改”提示改一两个数字，观察变化。需要改的地方都标了 `← 改这里`。Python 的基本语法在《Python 编程》课里学，本书不再重复。遇到看不懂的术语，把鼠标停在带虚线下划线的词上就能看到定义，或者查[附录 C 术语表](../appendix/glossary.md)。

??? question "TTS、STT、ASR、SST 到底有什么区别？"

    TTS 是语音合成（文字变声音）；ASR 和 STT 都是语音识别（声音变文字），只是叫法不同；课程名里的 SST 在业内不是通用缩写，本课程用它指“语音识别与合成”两个方向。详见 [1.4 节](../chapters/01-overview/index.md#14)。

??? question "书上标着“待实测”的实验是什么意思？"

    这些实验需要 GPU、国外网站或付费的云服务，编者的编写环境无法运行，所以没有给出运行结果，代码是按官方文档编写的。请你运行后把结果填进[附录 B](../appendix/b-environment.md#b7) 的待实测记录表。

??? question "书里的运行结果和我运行出来的不一样，是我做错了吗？"

    不一定。耗时和实时率和电脑快慢有关；合成和克隆每次都带一点随机性（[6.2.3 节](../chapters/06-tts-practice/index.md#623)），相似度、字错率会在小数位上波动。大致相同就说明做对了；差得很多再对照每章末尾的“常见报错”表排查。

## 实验环境与排错 { #faq-2 }

??? question "没有显卡能做实验吗？"

    能。除了两个拓展实验（7-4 语音转换、8-4 微调式克隆），全书实验都只用 CPU，普通 4 核笔记本几秒钟就出结果。详见[附录 B](../appendix/b-environment.md#b1)。

??? question "模型下载很慢或者中途断了怎么办？"

    再运行一遍同样的命令，`models.py` 会接着已下载的部分继续。还不行，可以向老师要离线包，或从魔搭社区的镜像下载后放进 `labs/models/<模型名>/`。详见[附录 B“模型下载不了怎么办”](../appendix/b-environment.md#b3-1)。

??? question "运行时提示 `No module named 'voicelab'` 或找不到 `../data/...`？"

    运行实验前要先进入这一章的文件夹（例如 `cd ch04`），再运行 `python lab4_1_compare_models.py`。实验程序用相对路径找上一级的 `voicelab.py` 和 `data` 文件夹。详见[附录 B 常见安装问题](../appendix/b-environment.md#b8)。

??? question "导出 MP3 时报错 `FileNotFoundError: [WinError 2]`？"

    电脑上没装 ffmpeg，或者装了但没加到 PATH。按[附录 B.5 节](../appendix/b-environment.md#b5)安装后重新打开命令行窗口。暂时装不上的，可以只保存 WAV 文件。

??? question "图上的中文变成了方框？"

    电脑缺少程序里列出的中文字体。Windows 一般自带“微软雅黑”，Linux 可以安装文泉驿字体。运行时出现的 `findfont` 提示不影响结果。详见第 2 章实验前的说明和[附录 B](../appendix/b-environment.md#b8)。

??? question "云端 Notebook 和自己电脑选哪个？"

    刚开始推荐用云端 Notebook，不用装软件；做综合项目、处理含个人信息的录音时，推荐用自己的电脑。注意免费 Notebook 关闭后模型可能被清空。详见 [1.5.3 节](../chapters/01-overview/index.md#153)和[附录 B.4 节](../appendix/b-environment.md#b4)。

## 语音识别 { #faq-3 }

??? question "为什么所有录音都要先转成 16 kHz 单声道？"

    本书的识别模型和声纹模型都是用 16 kHz 单声道录音训练的，喂给它别的格式，效果会变差甚至出错。`read_audio` 默认就会帮你转换。详见 [2.6.1 节](../chapters/02-audio/index.md#261)。

??? question "SenseVoice、Paraformer、Whisper 该选哪个？"

    中文普通话日常使用选 SenseVoice（快、带标点、数字写成阿拉伯数字）；要识别多种语言可以试 Whisper；Paraformer 是中文专用的轻量选择。实验 4-1 比较了三者的字错率和速度。详见 [4.1 节](../chapters/04-asr-practice/index.md#41)。

??? question "地名、人名总是识别错，有办法吗？"

    有两个办法：支持热词的模型可以加热词文件，让它更倾向于这些词；不支持热词的，可以识别完再用拼音比对纠错。详见 [4.7.1 节](../chapters/04-asr-practice/index.md#471)和实验 4-4。

??? question "字错率能超过 100% 吗？"

    能。字错率 =（替换 + 删除 + 插入）÷ 标准文字的字数，识别结果多出很多字时，插入错误可能比标准文字还多。详见 [3.7.1 节](../chapters/03-asr-principles/index.md#371)。

??? question "流式识别和非流式识别有什么不同？"

    非流式等一整句说完再识别，准确率高，适合录音转写；流式边听边出字，适合实时字幕和语音助手。详见 [4.5 节](../chapters/04-asr-practice/index.md#45)。

## 语音合成 { #faq-4 }

??? question "合成的声音把数字、日期读错了怎么办？"

    这是文本前端（文本正则化）的问题。可以先在文字里把数字写成想要的读法，例如“2026 年”写成“二〇二六年”，或者打开模型的数字、日期规则。注意 Matcha 不认识“〇”，要换成“零”。详见 [5.3.1 节](../chapters/05-tts-principles/index.md#531)和 [6.4.3 节](../chapters/06-tts-practice/index.md#643)。

??? question "长文章一次合成很慢，还容易出问题？"

    长文本要先分句，一句一句合成再拼起来，句子之间插入适当的静音。实验 6-3 用这个方法把 1469 字的告居民书做成了 5 分半钟的有声书。详见 [6.4.2 节](../chapters/06-tts-practice/index.md#642)和 [6.5 节](../chapters/06-tts-practice/index.md#65)。

??? question "中英文混在一起的句子怎么读得好？"

    选专门支持中英混读的 MeloTTS；或者把英文缩写改写成好读的形式，例如“APP”写成“A P P”。详见 [6.4.4 节](../chapters/06-tts-practice/index.md#644)。

??? question "声码器是做什么的？"

    声学模型只输出梅尔频谱，声码器把频谱“演奏”成能播放的声音波形。同一个声学模型换不同的声码器，音质会不同。详见 [5.5 节](../chapters/05-tts-principles/index.md#55)。

## 声纹与语音克隆 { #faq-5 }

??? question "声纹相似度多少算同一个人？"

    没有统一答案，要用自己的数据定门槛。本书的测试里，同一人在 0.83 以上、不同人在 0.68 以下；门槛定高了本人常被拒（拒识），定低了冒充者容易通过（误识）。详见 [7.3 节](../chapters/07-speaker/index.md#73)和实验 7-2。

??? question "用手机打电话的录音做声纹登录，为什么老是失败？"

    电话音质和注册时的录音差别很大，本书实验里电话音质的平均相似度只有 0.59，在 0.75 的门槛下本人全部被拒。注册和使用要尽量用同样的设备和音质。详见实验 7-2。

??? question "零样本克隆需要多长的参考音？"

    本书实验里，不到 3 秒的参考音就能克隆出相似度 0.70 的声音，再长提升不大；参考音更要紧的是干净、只有一个人、文字一字不差。详见 [8.3 节](../chapters/08-voice-cloning/index.md#83)和实验 8-2。

??? question "克隆出来的声音能骗过声纹识别吗？"

    有可能。本书实验中，不到 3 秒参考音克隆出的声音相似度为 0.70，已经高于实验 7-2 里“零错误”门槛范围的下限 0.68。所以声纹不能作为唯一的身份核验方式，涉及钱的操作一定要有第二道核验。详见 [7.5.2 节](../chapters/07-speaker/index.md#752)。

??? question "微调式克隆和零样本克隆有什么区别？"

    微调式要几分钟到几十分钟录音、用 GPU 训练一会儿，得到这个人专用的模型；零样本只要几秒参考音，不用训练，现场就能克隆，但相似度通常低一些。详见 [8.2.1 节](../chapters/08-voice-cloning/index.md#821)。

## 授权、合规与安全 { #faq-6 }

??? question "我能克隆明星或者网上视频里的声音吗？"

    不能。声音受《民法典》保护，克隆谁的声音必须先取得谁的书面授权；公众人物、网上下载的录音、模型包自带的示例音频都不要用。本书的实验只用虚拟授权人或你自己签了授权书的声音。详见 [8.6 节](../chapters/08-voice-cloning/index.md#86)。

??? question "用自己的声音做作业也要签授权书吗？"

    要。签授权书本身就是练习：授权人和被授权人都写自己，用途写课程作业，发布范围写仅提交给任课教师。模板见[附录 D.2 节](../appendix/d-templates.md#d2)。

??? question "AI 合成的声音一定要标识吗？怎么标？"

    要。按《人工智能生成合成内容标识办法》，发布的合成语音要有显式标识（开头的语音提示）和隐式标识（文件元数据），转格式后也要保留。实验 8-3 把两种标识和简单水印都做了一遍。详见 [6.7 节](../chapters/06-tts-practice/index.md#67)和 [8.6.5 节](../chapters/08-voice-cloning/index.md#865)。

??? question "接到“亲人”打来要钱的电话，声音一模一样，怎么办？"

    先挂断，用自己手机里存的号码回拨确认；家人之间约一个暗号；拿不准就拨打 96110 反诈专线。详见 [8.8.2 节](../chapters/08-voice-cloning/index.md#882)。

??? question "云平台的 API Key 可以写在代码里吗？"

    不要。密钥写在代码里，一旦上传到网上，别人就能用你的账号计费。放进环境变量，用 `os.environ` 读取。详见[附录 A.6 节](../appendix/a-libraries.md#a6-1)。
