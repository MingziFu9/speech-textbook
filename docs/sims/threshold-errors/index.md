## 教学说明

**学习目标**

1. 能说出误接受率和误拒绝率的含义，解释两者为什么此消彼长（理解）；
2. 能根据应用场景选择门槛，并说明录音条件变化对声纹验证的影响（应用、评价）。

**画面与操作**

- 绿色直方图是本人测试的分数，红色是冒充者的分数，黑色竖线是门槛；拖动滑块改变门槛，表格显示两种错误率。
- 上方可以切换“正常录音”和“电话音质”两组数据。

**数据来源**：实验 7-2 的实测分数（16 次本人测试、112 次冒充测试），电话音质是把测试录音降到 8 kHz 后重新计算的。

**课堂用法建议**

1. 正常录音下找出“两种错误都为 0”的门槛范围，再切换到电话音质，看同一个门槛的误拒绝率变成多少。
2. 讨论：银行转账和小区门禁，门槛应该偏高还是偏低？
