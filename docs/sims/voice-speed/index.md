## 教学说明

**学习目标**

1. 能说出说话人编号和语速两个参数分别改变了什么（理解）；
2. 能从时长、平均音高、采样率三方面比较不同模型的输出（分析）。

**画面与操作**

- 上面六个按钮选声音，下面三个按钮选语速（0.8 慢、1.0 正常、1.3 快）。
- 语谱图横轴固定 7 秒，语速越快，语谱图越短；表格给出时长、平均音高、采样率和最高能记录的频率。

**数据来源**：18 段声音全部由编者用 sherpa-onnx 在笔记本电脑 CPU 上合成（模型见 6.1 节的表），平均音高用 librosa 的 pyin 函数估计，声音转成了 48 kbps 的 MP3。

**课堂用法建议**

1. 先让学生只听不看，猜哪段是男声、哪段是女声，再看平均音高验证。
2. 选 VITS AISHELL-3，引导学生发现语谱图 4000 Hz 以上是空的，联系第 2 章的采样定理。
3. 比较语速 0.8 和 1.3 的平均音高，说明“语速”只改快慢、不改音调。
