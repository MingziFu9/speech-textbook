## 教学说明

**学习目标**

1. 能说出语音活动检测（VAD）的作用（记忆）；
2. 能解释“最短静音”“最短语音”两个参数对切句结果的影响，并为一段录音选择合适的参数（应用）。

**画面与操作**

- 灰色柱子是录音每 50 毫秒的音量（分贝），红色虚线是音量门槛，绿色方块是检测出的语音段，底部蓝条是标准答案的 7 句话。
- 三个滑块：音量门槛、最短静音（静音超过它才算一句结束）、最短语音（短于它的声音丢掉）。

**数据来源**：音量取自本书实验数据 `labs/data/meeting/meeting.wav`（加了很小的底噪），标准答案取自 `meeting_truth.csv`。动画用“音量超过门槛”做简化的检测，真实的 Silero VAD 判断的是“像不像人声”。

**课堂用法建议**

1. 先把“最短静音”调到 0.1 秒，请学生数切出几段，讨论为什么一句话被切成了几截；再慢慢调大到刚好 7 段。
2. 讨论：做字幕时切得太长、太短各有什么问题？
