## 教学说明

**学习目标**

1. 能说出参考音长度、生成步数对零样本克隆的影响（理解）；
2. 能用声纹相似度和实时率客观比较不同设置（分析），并认识到“几秒就能克隆”带来的风险（评价）。

**画面与操作**

- 上方切换“改参考时长”和“改生成步数”，拖动滑块选择设置；可以播放参考音、克隆结果和 B 的真实录音。
- 条形图显示克隆结果“像 B”的相似度、和其他志愿者的最高相似度，以及实时率。

**数据来源**：实验 8-2 在编者笔记本电脑 CPU 上的实测，ZipVoice int8 模型，参考音来自虚拟授权人 B（Kokoro 45 号音色合成）。

**课堂用法建议**

1. 先听 3 秒参考音的克隆结果，请学生猜要多长的参考音，再揭晓。
2. 联系第 7 章：克隆结果相似度 0.70，如果声纹登录门槛设在 0.68，会发生什么？
