## 教学说明

**学习目标**

1. 能区分替换、删除、插入三种错误（理解）；
2. 能手算并用工具验算一句话的字错率（应用）。

**画面与操作**

- 输入参考答案和识别结果，或点上方的例子；对齐结果中，绿色是对的，橙色是替换，红色是删除（漏了），蓝色是插入（多了）。
- 两个勾选框：去掉标点和空格（默认勾选）、统一数字写法（把“五”换成“5”）。

**数据来源**：例子取自第 2、3 章实验中模型真实的识别错误；算法是编辑距离，与 `labs/voicelab.py` 中的 `cer` 函数相同。

**课堂用法建议**

1. 先让学生手算 3.7.1 节的三个例子，再用计算器核对。
2. 用“写法不同”的例子讨论：“五号楼”识别成“5号楼”算不算错？引出“先统一写法再算字错率”。
