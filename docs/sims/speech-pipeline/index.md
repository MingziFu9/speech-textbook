## 教学说明

**学习目标**

1. 能说出一次语音对话经过的五个环节，以及每个环节的输入和输出（记忆）；
2. 能解释为什么“理解”这一步的做法会影响用户等待的时间（理解）。

**画面与操作**

- 上方是五个环节，点哪个，下面就显示它的输入、输出和作用。
- “理解这一步用”可以切换“关键词规则”和“大模型”，下方彩色条显示每一步占用的时间，并给出总等待时间。

**数据来源**：识别和合成的耗时取自实验 1-3 的实测（识别 7.0 秒来电用 0.39 秒，合成 7.0 秒回复用 0.53 秒，4 核 CPU、2 线程、不含第一次加载模型）。唤醒的 0.1 秒是按每 0.1 秒检测一次估算的；大模型的 0.6 秒、0.9 秒是示意值。

**课堂用法建议**

1. 让学生先猜“哪一步最慢”，再点开看；对比切换到大模型后的变化。
2. 讨论：智能音箱为什么不把所有声音都上传到云端识别？（省流量、省电，更重要的是保护隐私。）
