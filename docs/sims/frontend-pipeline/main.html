分词结果里有些切分并不理想（如“二零二 / 六年”“百分之十 / 二点五”），这是通用分词词典对数字读法不熟悉造成的，好在不影响注音。“一楼”被读成 yì lóu 是规则变调的错误（应读 yī lóu），实验 5-1 的思考题请你修正它。
