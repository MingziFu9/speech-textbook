## 教学说明

**学习目标**

1. 能说出文本前端的四个步骤及各自的作用（记忆、理解）；
2. 能指出一句话中需要正则化的数字符号、多音字和变调的字（应用）。

**画面与操作**

- 选一个例句，按“下一步”依次展开四个步骤；原文中需要正则化的部分用黄色标出，注音中的多音字和变调字用橙色标出。

**数据来源**：四个例句的各步结果由 `labs/ch05/frontend.py`（实验 5-1 的前端程序）预先算好写入网页；韵律停顿按“词间 #1、逗号 #3、句末 #4”的简化规则标注。

**课堂用法建议**

1. 先只给学生看原文，请他们圈出“机器可能读错”的地方，再逐步展开核对。
2. 例句 2 中“一楼”被读成 yì lóu，请学生讨论应该怎样修改变调规则。
