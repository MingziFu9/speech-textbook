# 2.1 声音是什么

## 振动和声波
- 声带振动 → 推动空气一疏一密 → **声波**
- **频率**：每秒振动几次（Hz）
- **振幅**：每次偏离多大
- 人耳能听 20—20000 Hz，年纪越大高频越差
::: notes
用手指按住喉咙说“啊——”，能感觉到喉咙在微微振动。所有的声音都来自振动：说话时声带振动，敲门时门板振动，弹吉他时琴弦振动。
振动的物体会推动周围的空气：往外推时，空气被挤得密一些；往回缩时，空气变得疏一些。这种一疏一密的变化像水波一样一圈圈传出去，就是声波。声波传到耳朵，推动鼓膜跟着振动，我们就听到了声音。话筒的原理和耳朵一样：里面有一片很薄的膜，跟着空气振动，再把振动变成电信号。
把空气在某一点的“疏密程度”随时间的变化画出来，就是一条上下起伏的曲线。描述这条曲线有两个最基本的量：
人耳大约能听到 20 Hz 到 20000 Hz 的声音，年纪越大，高频听得越差。人说话的声音主要集中在 100 Hz 到 4000 Hz 之间，清辅音（比如“s”“x”）的能量可以到 8000 Hz 左右。记住这几个数字，2.2 节选采样率时要用。
:::

## 2.1.2 音高、响度和音色

| 听起来 | 叫作 | 主要由什么决定 | 例子 |
|---|---|---|---|
| 高还是低 | 音高 | 频率：频率越高，音越高 | 女声一般比男声高；口哨比说话高得多 |
| 响还是轻 | 响度 | 振幅：振幅越大，越响 | 离话筒近、说话用力，录音的振幅就大 |
| 像谁、像什么 | 音色 | 声音里各种频率成分的搭配 | 闭着眼也能听出是妈妈还是爸爸在说话 |

::: notes
我们平时描述一个声音，会说它“高不高”“响不响”“好不好听”。这三种感觉分别对应声音的三个特性：
说话时声带每秒振动的次数叫基频，它决定了我们听到的音高。成年男性的基频大约在 100—150 Hz，成年女性大约在 200—250 Hz，儿童更高。说话时基频不停地起伏，就形成了语调；普通话的四个声调，就是基频在一个字里“平、升、降升、降”的变化。
音色要复杂一些。声带振动发出的声音不是单一频率，除了基频，还带着 2 倍、3 倍、4 倍……基频的“谐波”。这些声音经过喉咙、口腔、鼻腔时，有的频率被放大，有的被减弱，就像对着一个罐子说话，声音会变“嗡嗡”的。口腔、鼻腔放大的那几个频率区域叫共振峰。
共振峰决定了发的是哪个元音。试着连续说“啊—衣—乌”：音高可以不变，但嘴巴张开的大小、舌头的位置在变，口腔这个“共鸣箱”的形状变了，共振峰就跟着变。
表中是大致数值，不同的人会有差别，但三个元音之间的相对关系是稳定的。本章实验数据里的三个元音就是按这张表“合成”出来的（`labs/data/make_audio.py`），实验 2-1 会把它们画出来。

# 2.2 把声音存进电脑

## 采样：每秒记多少次
- **采样**：每隔一小段时间记一次高度
- **采样率**：每秒记多少次
- **采样定理**：最高能记录采样率的**一半**
- 采样率不够 → **混叠**，高频变成假的低频
- 说话主要在 8000 Hz 以下 → **16 kHz 够用**
::: notes
采样就是每隔相同的一小段时间，记下一次声波此刻的高度。就像拍电影：真实世界是连续的，电影每秒拍 24 张照片，连起来放，看起来就是连续的动作。
每秒记多少次，叫采样率，单位也是 Hz。第 1 章实验 1-1 里 `sr` 等于 22050，意思就是每秒记 22050 个数字；7.32 秒的语音一共 161465 个采样点，161465 ÷ 22050 ≈ 7.32，正好对上。
常见的采样率有这几种：
为什么“能记录的最高频率”正好是采样率的一半？这就是采样定理（也叫奈奎斯特定理）：
直观地想：一次振动有一“上”一“下”，每次振动至少要记两个点，一个落在上半段、一个落在下半段，才能知道“它振动了一次”。如果记得太稀，一个 6000 Hz 的声音用 8000 Hz 采样，采样点连起来会变成一个 2000 Hz 的假声音，这种现象叫混叠。电影里飞速转动的车轮看起来像在倒着转，也是同样的道理。所以录音设备在采样之前，都会先把超过一半采样率的高频滤掉。
人说话的主要信息在 8000 Hz 以下，所以 16 kHz 对语音识别已经够用；电话只有 8 kHz，“s”“f”这些高频的清辅音就被削掉了，这就是电话里的声音听着发闷、容易把“四”和“十”听混的原因。
:::

## 2.2.1 采样：每秒记多少次

| 采样率 | 能记录的最高频率 | 常见用途 |
|---|---|---|
| 8000 Hz（8 kHz） | 4000 Hz | 固定电话、老式电话录音 |
| 16000 Hz（16 kHz） | 8000 Hz | 语音识别、声纹识别的标准输入，本书识别实验统一用它 |
| 22050 / 24000 Hz | 约 11—12 kHz | 很多语音合成模型的输出 |
| 44100 Hz（44.1 kHz） | 22050 Hz | CD、音乐、手机录音 |
| 48000 Hz（48 kHz） | 24000 Hz | 视频、专业录音 |


## 量化：每个点记多细
!sim sampling-quantization
- **位深**：每个点用几位二进制数存
- 16 位 = 65536 个台阶
- Python 里换成 −1 到 1 的小数
::: notes
采样决定“多久记一次”，量化决定“每次记得多细”。声波的高度是连续的，可以是 0.31415926……，但电脑存一个数要用固定的位数，只能把高度四舍五入到最近的一个“台阶”上。

## 2.2.2 量化：每个点记多细

| 位深 | 台阶个数 | 听起来 |
|---|---|---|
| 8 位 | 2⁸ = 256 | 有明显的“沙沙”底噪，老式游戏机的声音 |
| 16 位 | 2¹⁶ = 65536 | 足够细，人耳听不出台阶，WAV 和 CD 的标准 |
| 24 位 | 约 1678 万 | 专业录音棚用，给后期处理留余量 |


## 声道和文件大小
- **声道**：同时录几路（单声道 / 双声道）
- 文件大小 = 采样率 × 位深 ÷ 8 × 声道 × 秒数
- 算一算：16 kHz、16 位、单声道、1 分钟
  - 16000 × 16 ÷ 8 × 1 × 60 = 1 920 000 字节 ≈ **1.83 MB**
- 44.1 kHz 立体声：约 **10.1 MB**，是 5.5 倍
::: notes
声道是同时录下的声音有几路。单声道只有 1 路；立体声有左、右 2 路，戴耳机听音乐时声音有“方位感”就靠它。语音识别只关心说了什么，不需要方位，所以识别前一般把立体声的两路取平均，合成单声道。本书的 `read_audio` 函数就是这样做的。

# 2.4 看声音的三种图

## 波形图：声音的“心电图”
- 横轴时间，纵轴振幅
- 静音：贴着 0 的直线
- **削波**：波峰被齐刷刷切平
- 底噪：静音处一层“草”
- 看不出“是什么声音”
::: notes
波形图就是把采样点直接画出来：横轴是时间，纵轴是振幅。它像心电图，能直接看出：
但波形图看不出“是什么声音”：“啊”和“衣”的波形看起来都是一团密密的线。要看声音的内容，得看频率。
:::

## 频谱：由哪些频率组成
- 像三棱镜把白光分成七色
- 口哨：一个尖峰
- 元音：一排等间隔尖峰（基频和谐波），包络上的山包是**共振峰**
- 噪声：一片平坦
::: notes
白光通过三棱镜，会分成红橙黄绿青蓝紫。一段声音也可以“分解”成不同频率的成分，每个频率有多强，画出来就是频谱：横轴是频率，纵轴是这个频率的强度。把声音分解成频率的数学方法叫“傅里叶变换”，程序里一行代码就能完成，我们只用它的结果。
:::

# 2.5 梅尔频谱与 MFCC

## 人耳的“刻度”：梅尔
- 人耳对低频敏感、对高频迟钝
- 100→200 Hz 差别大，8000→8100 Hz 几乎听不出
- **梅尔频谱**：按人耳感觉合并成 80 个频带
- 今天识别、合成模型的标准“原料”
::: notes
人耳对低频的变化很敏感，对高频的变化很迟钝：100 Hz 和 200 Hz 听起来差别很大，但 8000 Hz 和 8100 Hz 几乎听不出差别。1937 年，心理学家史蒂文斯（S. S. Stevens）等人请听众比较音高，总结出一种“按人耳感觉划分”的音高刻度，叫梅尔（Mel）刻度：低频处划分得细，高频处划分得粗。
把语谱图的 257 个频率格子，按梅尔刻度重新合并成几十个频带（常用 80 个），低频的格子几乎不合并、高频的格子大把合并，再对强度取对数（人耳对响度的感觉也是“对数”的：能量变成 10 倍，听起来只是响了一截），就得到了梅尔频谱。
梅尔频谱是今天语音模型最常用的“原料”：本书用到的识别模型 SenseVoice、Paraformer、Whisper，输入都是 80 个频带左右的梅尔频谱；合成模型 Matcha-TTS 先“画”出一张梅尔频谱，再交给声码器变成声音（第 5 章）。
:::

## MFCC：再压缩成十几个数
!mermaid 1
- 每帧只留 13 个数
- 传统识别（DTW、HMM）常用
::: notes
在梅尔频谱的基础上，再做一次数学变换（离散余弦变换），把每帧的几十个数进一步压缩，只保留前 13 个左右，就得到MFCC（梅尔频率倒谱系数）。这 13 个数概括了一帧声音“共振峰的大致形状”，而把基频的细节去掉了，正好是识别“说了什么”需要的。1980 年戴维斯（S. Davis）和默梅尔斯坦（P. Mermelstein）的实验表明 MFCC 比当时的其他特征识别效果更好，此后三十年它一直是语音识别的标准特征。第 3 章的模板匹配和 HMM 实验就用 MFCC。

| 梅尔频谱 | 约 8000（80 × 100 帧） | 今天的识别、合成模型 |
| MFCC | 约 1300（13 × 100 帧） | 传统识别（DTW、HMM）、第 3 章实验 |


# 2.6 音频处理基本功

## 格式统一、去静音、归一化
- **单声道、16 kHz**：`read_audio(文件, sr=16000)`
- 降采样先滤高频，否则混叠
- **去首尾静音**：按音量找开头结尾
- **音量归一化**：峰值放到 0.9 左右
- 缺点：一声咳嗽决定整段音量
::: notes
识别模型一般要求输入单声道、16 kHz。遇到立体声，就把两个声道取平均；遇到其他采样率，就做重采样。
本书的 `read_audio(文件, sr=16000)` 已经把“取平均变单声道”和“重采样”包在一起，读进来就是 16 kHz 单声道。
:::

## 噪声和降噪
- 先估计噪声在各频率的强度，再从整段里减掉
- **降噪不是越狠越好**：人声发“水”、发“闷”
- 降噪**不一定**帮助识别（实验 2-4）
::: notes
录音里除了人声，常常还混着空调声、车流声、电流的嘶嘶声。人声和噪声的强弱之比叫信噪比（SNR），用分贝（dB）表示：
降噪的基本思路是：先找一段“只有噪声”的部分，算出噪声在各个频率上大概有多强，然后在整段录音的语谱图上，把每个频率减去这么多。这种方法叫“谱减法”，对空调、风扇这种稳定不变的噪声效果好，对突然的关门声、旁人说话就无能为力。本书用的 `noisereduce` 库就是在这个思路上改进的。
降噪不是越狠越好：减得太多，人声也会被减掉一部分，变得发“水”、发“闷”，还会出现像金属声一样的“音乐噪声”。今天的识别模型在训练时就见过大量带噪声的录音，对一般的噪声已经很“抗”，降噪有时反而会帮倒忙。实验 2-4 用数据说话。
:::

## 2.6.4 噪声和降噪

| 信噪比 | 含义 | 听起来 |
|---|---|---|
| 30 dB 以上 | 人声能量是噪声的 1000 倍以上 | 很干净，安静房间里录的 |
| 10 dB | 人声是噪声的 10 倍 | 能听出背景有声音，但不影响听清 |
| 0 dB | 人声和噪声一样强 | 很吵，要仔细听 |
| 负数 | 噪声比人声还强 | 很难听清 |


## 2.7 录一段好录音

| 项目 | 要求 | 为什么 |
|---|---|---|
| 环境 | 安静的房间，关掉空调、风扇，远离马路；有窗帘、沙发的房间比空荡荡的房间好 | 减少噪声和回声 |
| 距离 | 嘴离手机话筒 15—30 厘米，正对或稍偏一点 | 太远声音小、回声大；太近容易削波、有“噗噗”的喷麦声 |
| 音量 | 正常说话的音量，录完看波形图，最响处在 0.3—0.8 之间 | 太小噪声相对大，太大会削波 |
| 首尾 | 按下录音后停 1 秒再说，说完停 1 秒再停止 | 防止字头字尾被切掉，事后再剪 |
| 格式 | 能选的话选 WAV、16 kHz 或以上；只能录 M4A 也可以，事后转换 | 有损压缩会丢细节 |
| 内容 | 照稿子读，记下读的原文 | 识别实验要用原文算字错率；克隆参考音也要对应的文字 |
| 告知 | 录别人之前说明用途，取得同意 | 声音是个人信息（1.6 节、第 8 章） |

:::

## 前沿视窗：把声音变成“词”
- 神经网络音频编解码器：3 kbps 胜过 12 kbps 的 Opus
- 一段声音 → 一串整数编号，像一个个“词”
- 大模型就能像处理文字一样处理声音
::: notes
神经网络音频编解码器：把声音变成“词”。MP3、Opus 这些传统格式是工程师根据人耳的特点一点点设计出来的。2021 年起，谷歌的 SoundStream、Meta 的 EnCodec 等“神经网络编解码器”出现了：用神经网络学会怎样压缩声音，在每秒只有 1.5—6 千位（kbps）的极低码率下，音质仍然比同码率的传统格式好得多。
更重要的是，这类编解码器把一段声音变成了一串整数编号，就像把一句话切成一个个“词”。有了“声音的词”，大语言模型就可以像续写文字一样“续写声音”：第 1 章提到的语音大模型、第 8 章的大模型语音克隆，很多都是这么做的。所以，“声音怎么变成数字”这个老问题，今天又有了新的答案：从采样点，到梅尔频谱，再到“声音的词”。
截至 2026 年 10 月，主流的语音识别模型仍以梅尔频谱为输入，而新一代的语音合成和语音大模型越来越多地使用这种“声音的词”。本书用到的模型两种都有，后面遇到时会指出来。
:::

## 本章小结
- 声音：频率定音高，振幅定响度，频率搭配定音色

- 波形图看音量，语谱图看内容
- 梅尔频谱是模型的标准输入
- 最好的处理是一开始就录好
